# rat-dashboard
NYC Rat Sightings Dashboard

Aidan Hornblow – BITM3747 HYA – Fall

An interactive dashboard analyzing 114,507 NYC rat sightings from 2010 to 2018.

Features

Borough filtering

Summary statistics and charts

Monthly trends and linear regression forecasting

Seasonal heatmap

Interactive NYC map using Esri basemap tiles

Data Source

NYC Rat Sightings dataset

Technologies

HTML, CSS, JavaScript, and Esri mapping services.
